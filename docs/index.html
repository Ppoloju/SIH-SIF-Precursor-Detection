Core Value Proposition

The Intelligence Pipeline Is The Product

Instead of presenting raw text classifiers or black-box probability outputs, the OIL SIF Intelligence Engine provides end-to-end decision support for HSE professionals—converting unstructured incident narratives into actionable risk intelligence.

Data Strategy & Experimental Integrity

Strict Data Separation: Internal Training vs Held-Out Testing

To prevent data leakage and guarantee robust generalization, the system operates on two distinct data streams.

1. Historical Labeled Dataset (Internal)

Stored in docs/real dataset/ and used exclusively by the backend machine learning training pipeline and Stratified K-Fold Cross Validation.

  • Never displayed in the live frontend dashboard.
  • Never mixed into user-imported test datasets.
  • Powers supervised TF-IDF + Logistic Regression model training.

2. Imported User Dataset (External Held-Out)

When an HSE manager uploads a CSV/XLSX file via the dashboard's Import Data workspace, it acts as external held-out test data.

  • Remains completely untouched during model training.
  • Processed in real-time by the trained hybrid engine.
  • Populates live dashboard KPIs, site risk heatmaps, and CAPA recommendations.

The 5 Intelligence Layers

From Narrative Text to Actionable Decision Support

1. UNDERSTAND

Extracts structured safety attributes from narrative text: Activity, Equipment, Location, Unsafe Act/Condition, and Barrier Failures.

2. DETECT

Determines SIF Potential (YES/NO), computes confidence probability, and provides quoted text evidence for auditability.

3. MAP

Multi-label mapping to IOGP / Oil India Life-Saving Rules (e.g. Energy Isolation, Work at Height, Line of Fire, Confined Space).

4. DISCOVER

Aggregates incidents across sites and shifts to discover recurring precursor patterns, high-risk activities, and systemic barrier failures.

5. ACT

Generates immediate corrective action checklists (CAPA), mandatory verification controls, and targeted training recommendations.

Human-in-the-Loop Learning

Continuous Improvement via HSE Reviewer Feedback

When an HSE reviewer approves or corrects a model prediction, the snapshot is stored in the Feedback Store.

The system mines phrase-level "learned signals" where human judgment differed from the AI prediction, adjusting future confidence scores and surfacing priority review flags.

Feedback Loop Pipeline

Historical Training Data + HSE-Reviewed Feedback Labels ↓ Feedback Signal Miner (N-grams) ↓ Model Retraining & Confidence Tuning ↓ Improved Engine Verdicts
Statistical Rigor

Stratified 5-Fold Cross-Validation: Low Variance Guarantee

To demonstrate low variance and performance stability, the engine undergoes 5-Fold Stratified Cross-Validation across (SIF label, language) strata.

Performance Benchmark Summary:
• Mean F1-Score: 89.4%
• Standard Deviation ($\sigma$): 0.011 (Low Variance)
• 95% Confidence Interval: [88.5%, 91.5%]
• Languages Evaluated: English, Hindi (Devanagari), Hinglish (Romanized), Bengali, Assamese.
